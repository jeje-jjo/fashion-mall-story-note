# 패션몰스토리 노트 — 아이콘 요청서

## 1. 앱 소개
- 게임 「패션몰스토리」 진행을 기록하는 개인 노트 웹앱이다.
- 휴대폰 화면이 가장 중요하다. 아이패드와 맥에서도 쓴다.
- 분위기: 따뜻한 종이색 바탕, 빈티지 로즈 강조색, 차분하고 정돈된 다이어리 느낌.

## 2. 그림 규칙
- 캔버스 24×24, 안쪽 여백 2~3px. 모든 아이콘의 크기와 무게가 같아 보여야 한다.
- 선 아이콘. 선 굵기 1.75px(24px 기준), 끝과 꺾임은 둥글게.
- 면은 탭 아이콘에만 옅게(선 색 16%) 써도 된다. 그라데이션, 그림자, 입체감은 쓰지 않는다.
- 색은 한 가지(선 색)만 쓴다. 앱이 글자색으로 칠하므로 SVG는 `stroke="currentColor"`로 만든다.
- 실제 표시 크기:
  - 탭·오른쪽 둥근 버튼·최근 기록 버튼: 24px
  - 버튼 안 기호: 16px
  - 체크 칸·태그 안 기호: 12~14px
  - 12px로 줄여도 알아볼 수 있게 단순하게 그린다.
- 결과물: 아이콘마다 SVG 1개(viewBox 0 0 24 24, 배경 투명). 파일 이름은 아래 id를 쓴다(예: `clo.svg`).

### 앱 대표 아이콘 (별도)
- 쓰이는 곳: 머리줄 로고(32~36px), 로그인 화면(64px), 홈 화면 아이콘(180·192·512px), 파비콘(16·32px)
- 불투명 배경의 둥근 네모. 가운데에 쇼핑백 같은 상징 하나. 16px에서도 알아볼 만큼 단순하게.
- 필요한 크기: 512, 192, 180(apple-touch), 128, 64, 32, 16. 마스커블 512(가장자리 10% 안전 여백).
